Kebijakan Privasi

Cek Pajak Kendaraan Sumbar — versi 1.0.0

Berlaku sejak 18 Oktober 2026 · Aplikasi Android: id.iipnurafifah.cekpajaksumaterabarat
Dokumen ini menjelaskan bagaimana aplikasi Cek Pajak Kendaraan Sumbar menangani informasi Anda. Singkatnya: aplikasi ini tidak mengumpulkan data pribadi dan tidak memiliki server pengembang.

1. Ringkasan

  • Tidak ada pendaftaran akun, tidak ada nama/email/telepon yang diminta.
  • Aplikasi menampilkan iklan dari Google AdMob (banner & interstitial). Google serta mitranya dapat mengumpulkan ID iklan perangkat (advertising ID) untuk menayangkan dan mengukur iklan, tanpa data identitas dari kami. Lihat bagian 5.
  • Nomor polisi & nomor rangka yang Anda ketik dikirim hanya sekali ke server resmi Bapenda Sumatera Barat untuk memproses pengecekan, melalui koneksi terenkripsi HTTPS.
  • Riwayat pengecekan disimpan hanya di perangkat Anda dan dapat dihapus kapan saja.
  • Aplikasi tidak meminta izin sensitif (lokasi, kontak, kamera, mikrofon, penyimpanan).

2. Informasi yang diproses

a. Data yang Anda masukkan (nomor polisi, 5 digit terakhir nomor rangka, dan kode otorisasi bila ada) dikirim ke https://bapenda.sumbarprov.go.id sebagai permintaan pengecekan. Data tersebut tidak disimpan oleh pengembang — pengembang tidak memiliki server yang menerima data Anda.

b. Riwayat pengecekan (nomor polisi, merek/tipe kendaraan, tanggal, dan rincian tagihan) disimpan di penyimpanan lokal aplikasi (SharedPreferences) di perangkat Anda, maksimum 25 entri. Riwayat dapat dimatikan atau dikosongkan kapan saja melalui halaman Riwayat di aplikasi. Riwayat tidak ikut backup cloud karena backup aplikasi dinonaktifkan.

c. Log teknis perangkat. Aplikasi tidak membuat log pengguna dan tidak mengirimkannya ke mana pun. Sistem operasi Android dapat menampilkan log lokal sesuai kebijakan sistem.

3. Untuk apa data dipakai

  • Menampilkan hasil pengecekan pajak kendaraan (status pajak, denda, total tagihan).
  • Menyediakan riwayat pengecekan lokal agar Anda dapat mengecek ulang dengan cepat.

Pengembang tidak memakai data yang Anda masukkan untuk pemasaran, profiling, maupun analitik. Iklan Google AdMob diproses oleh Google terpisah dari data pengecekan (lihat bagian 9).

4. Dengan siapa data dibagikan

Permintaan pengecekan diteruskan langsung dari perangkat Anda ke server Bapenda Sumatera Barat (bapenda.sumbarprov.go.id), penyedia layanan resmi pemerintah provinsi. Pengembang tidak menerima, menyimpan, atau membagikan data Anda kepada pihak lain. Kebijakan privasi server pemerintah berlaku untuk pemrosesan di sisi mereka.

5. Keamanan

  • Semua komunikasi menggunakan HTTPS/TLS; lalu lintas HTTP (tanpa enkripsi) diblokir oleh konfigurasi keamanan jaringan aplikasi.
  • Kepercayaan hanya diberikan pada sertifikat bawaan sistem (menolak sertifikat yang dipasang pihak ketiga).
  • Input dibersihkan dan dibatasi panjangnya sebelum dikirim ke server.
  • Tanpa akun berarti tidak ada kredensial yang dapat bocor dari aplikasi ini.

6. Retensi & penghapusan

Data yang Anda ketik tidak disimpan pengembang. Riwayat lokal dapat Anda hapus kapan saja dari halaman Riwayat (hapus per entri atau hapus semua). Menghapus aplikasi juga menghapus seluruh riwayat lokal, karena data hanya ada di perangkat Anda.

7. Anak-anak

Aplikasi ini ditujukan untuk umum dan tidak mengumpulkan data pribadi apa pun, termasuk dari anak-anak di bawah 13 tahun.

8. Izin aplikasi

  • INTERNET — menghubungi server Bapenda untuk pengecekan dan memuat iklan.
  • ACCESS_NETWORK_STATE — menampilkan status koneksi; juga dibutuhkan SDK iklan.
  • AD_ID — izin standar yang dibutuhkan Google AdMob di Android 12+ untuk iklan.

Tidak ada izin lain: tanpa lokasi, kontak, kamera, mikrofon, penyimpanan, atau telepon.

9. Iklan (Google AdMob)

Aplikasi ini menggunakan Google AdMob untuk iklan banner dan interstitial. AdMob mungkin memproses advertising ID perangkat dan data telemetri iklan (mis. durasi tayang, klik) untuk layanan iklan dan agregasi. Pengembang aplikasi tidak menerima data ini dan tidak menargetkan iklan berdasarkan produk pencarian apa pun. Pengguna bisa menonaktifkan personalisasi iklan melalui Pengaturan Google → Iklan di perangkat Android. Detail resmi: google.com/policies/technologies/ads.

10. Perubahan kebijakan

Bila ada perubahan, versi kebijakan yang diperbarui akan dipublikasikan pada halaman ini beserta tanggal berlakunya. Perubahan materiil (misalnya penambahan jenis data yang diproses) akan dijelaskan secara jelas sebelum berlaku.
